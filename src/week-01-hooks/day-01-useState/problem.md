요구사항 — 기본 (필수)
상품 목록 렌더, 각 상품에 담기 버튼
장바구니 영역: 담긴 항목의 이름 / 수량 / 소계(price × qty)
각 항목에 + / − 버튼. 수량이 0이 되면 장바구니에서 제거
총 수량과 총 금액 표시 — 이 두 값에 useState를 쓰지 말 것. 렌더 중 장바구니 상태로부터 계산
모든 상태 갱신은 함수형 업데이트(setX(prev => ...))로. 이유를 회고에 적기

요구사항 — 응용
비우기 버튼
무료배송: 총 금액 30,000원 이상이면 배송비 0원, 미만이면 3,000원. 미만일 때 "N원 더 담으면 무료배송" 문구
재고 상한: 수량이 상품 stock에 도달하면 + 버튼 비활성화
장바구니를 localStorage에 저장·복원. 초기값 복원은 게으른 초기화(useState(() => ...))로

요구사항 — 도전
쿠폰 입력창. SAVE10 → 상품 합계 10% 할인, 그 외 → "유효하지 않은 코드". 할인이 배송비 판단 전/후 어느 금액 기준인지 스스로 정하고 근거를 회고에
장바구니 상태를 정규화(Record<productId, quantity>)해서 관리하고, 화면에 뿌릴 때 PRODUCTS와 조합. 배열로 들 때와 뭐가 다른지
같은 기능을 (a) useState 하나의 객체로, (b) 여러 개로 쪼개서 — 두 버전 구현하고 어느 쪽이 읽기 쉽고 버그가 적었는지 회고에
테스트 (처음부터 작성) — Cart.test.tsx
담기 버튼 → 장바구니에 항목이 나타난다
+ / − 로 수량이 바뀌고, 1에서 − → 항목이 사라진다
총 수량 / 총 금액이 장바구니 내용과 일치한다 (파생 계산 검증)
무료배송 경계: 합계 29,999원 → 배송비 표시, 30,000원 → 무료
(응용 9 구현 시) localStorage에 값이 있으면 첫 렌더에서 복원된다
